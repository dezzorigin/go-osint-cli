go-osint-cli mengecek satu username di GitHub, GitLab, Dev.to, Pinterest, dan Reddit — paralel, dari terminal, hasilnya berurutan dan jujur.

Lihat di GitHub → Cara install 
$ ./go-osint-cli dezzorigin

Scanning for 'dezzorigin' across 5 platforms...

[GitHub] Found -> https://github.com/dezzorigin
[GitLab] Redirect (Status: 302) — cannot verify (login wall?)
[Dev.to] Not Found (Available)
[Pinterest] Found -> https://www.pinterest.com/dezzorigin/
[Reddit] Found -> https://www.reddit.com/user/dezzorigin/

Scan completed in: 2.84s

Install

Butuh Go 1.26 atau lebih baru. Tidak ada dependensi di luar standard library.

# dari source
git clone https://github.com/dezzorigin/go-osint-cli.git
cd go-osint-cli
go build -o go-osint-cli .

# atau langsung dari Go
go install github.com/dezzorigin/go-osint-cli@latest

Cara pakai

# username sebagai argumen
./go-osint-cli dezzorigin

# atau interaktif — program bertanya dulu
./go-osint-cli
Enter username to check: dezzorigin

Satu kali jalan mengecek 5 platform sekaligus (paralel, timeout 10 detik per platform) lalu mencetak hasilnya dalam urutan platform yang tetap.

Platform yang dicek

PlatformMetodeArti hasil
GitHubGET github.com/<user>200 = ada, 404 = tersedia
GitLabGET gitlab.com/<user>sering redirect ke halaman login
Dev.toGET dev.to/<user>200 = ada, 404 = tersedia
PinterestGET pinterest.com/<user>/lihat catatan di bawah
RedditGET reddit.com/user/<user>/lihat catatan di bawah

Jujur soal batasnya

Tool ini membaca kode status HTTP saja. Dua hal yang perlu diketahui: Reddit dan Pinterest mengembalikan 200 untuk username apa pun — jadi “Found” di sana artinya halamannya merespons, bukan bukti akunnya ada. GitLab mengarahkan semua permintaan anonim ke halaman login (302), jadi hasilnya “cannot verify”. Jangan jadikan output ini satu-satunya bukti.

Detail lengkap, termasuk arsitektur dan diagram alur, ada di folder docs repo.
